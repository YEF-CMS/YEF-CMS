# Security Policy

YEF CMS is a hobby project provided "as is", without warranty (see [LICENSE](LICENSE)). Still, security reports are welcome.

Please report vulnerabilities privately through GitHub's "Report a vulnerability" feature on the
[YEF-CMS/YEF-CMS](https://github.com/YEF-CMS/YEF-CMS/security/advisories/new) repository rather than in a public issue.

Note that installing a module from GitHub executes that module's PHP code with the full rights of the site. Install only modules you trust.
